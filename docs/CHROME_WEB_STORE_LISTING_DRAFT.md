# Chrome Web Store listing draft — internal review only

Suggested listing name: Personal Outreach Copilot — LinkedIn Draft Assistant
Single-purpose summary: Draft personal connection notes and replies for your review. You send messages yourself.

## Description
Create personalized, editable connection notes and messaging replies from the profile or conversation you are viewing. The extension sends selected text to your configured local AI service for drafting, lets you review and edit the result, then inserts approved text in the visible composer. It never clicks Send or Connect for you.

An installed and running local gateway and language model are required. This product is independent and is not affiliated with or endorsed by LinkedIn.

## Required final listing inputs
- Accurate name, short/long descriptions, category and website.
- Real screenshots of a running version (1280×800), not invented visuals.
- 128×128 icon and promotional image compliant with Chrome Web Store image policy.
- Public, owner-approved privacy policy and developer support contact.
- Exact disclosures for website/profile/message data, local gateway use, and permission justifications.
- Chrome Web Store developer account and final review submission by owner.

Do not claim automatic messaging, guaranteed sales, remote SaaS functions, analytics, or payments that are not verified in the final installed build.
