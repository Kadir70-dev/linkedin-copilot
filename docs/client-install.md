# LinkedIn Copilot — install and use

You need two things from your administrator: the extension ZIP file and your personal **access key**. Keep the key private, like a password.

## Install (once)

1. Unzip the file into a folder you will keep (for example `Documents/LinkedIn Copilot`).
2. In Chrome, open `chrome://extensions` and turn on **Developer mode** (top right).
3. Click **Load unpacked** and pick that folder.
4. On the LinkedIn Copilot card, click **Details → Extension options**.
5. Paste your access key and click **Save and test**. You should see **Connected ✓**.

## Use

1. Open LinkedIn in Chrome and go to a message thread (**Get Suggestion**) or a profile (**Capture Profile → Generate Outreach**). For several profiles at once, use **Scan Profiles → Generate Outreach Queue**.
2. Wait for the draft. It can take up to a minute.
3. Read the draft. Click **Reject** if it isn't right.
4. Click **Approve → Inject** to put it into LinkedIn's message or note box. For a connection note, first open **Connect → Add a note** on LinkedIn.
5. Check and edit the text, then **press LinkedIn's Send button yourself**. Copilot never sends anything for you.

## If something goes wrong

- **"Gateway unavailable" or "Access key rejected"**: open Extension options and paste the key again. If it still fails, contact your administrator.
- **"Rate limited"**: wait one minute and try again.
- Don't share your key. If you think someone else has it, ask your administrator to replace it.
